# Write a five-beat demo script

## Hook
Every loan officer here knows the sinking feeling of finding a missing page after an hour of checking.

## Before
Today one file takes about 45 minutes, and the three of you check 400 files a month. Applicants wait days for a missing income proof to be noticed.

## Live moment
I will drop in one of your own anonymised files, a housing loan from last month. The tool lists three missing items in under a minute, and shows the page where it looked for each one.

## After
The same file now takes about 15 minutes, because the officer only handles the three flags and the judgement calls.

## Ask
Can we run a four week pilot on new files in this branch, starting on the first Monday of March?
