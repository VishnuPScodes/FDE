# Plan for the demo going wrong

## Likely failure
The Wi-Fi may drop, or the tool may take 40 seconds to answer. The second most likely problem is a file that is too large to upload.

## Say this
Let me use the recorded version while this loads. It shows the same case, and then we will come back to the live one.

## Fallback
I will carry a two minute screen recording, a mobile hotspot and printed screenshots of the key steps. The sample file is already uploaded before the meeting.

## Recover
After the recording I return to the live case if it is ready. If not, I stay with the recording and offer to run the live one on their data tomorrow, then move straight to the Ask.
