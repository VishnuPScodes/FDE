# Write a one-page staff guide

## What changes
New loan files go into the shared folder as before. The tool now checks them and shows you a list of missing pages in about a minute. You start from that list instead of reading every page.

## What stays the same
You still decide on every file. The tool never approves or rejects a loan. Your sign-off and your branch manager's approval work exactly as before.

## How to get help
Message the Aluva support group on WhatsApp, or call Anil on 98470 00000 between 10 and 5. Someone will reply within one working day.

## When the tool is wrong
If a flag is wrong, tap the "wrong flag" button and carry on. You will not be blamed for tool mistakes. Each report helps us fix it, and we tell you when it is fixed.
