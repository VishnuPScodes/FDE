# Work out the payback period

## Inputs
Setup cost: ₹1,50,000 one time. Staff time saved: ₹75,000 a month. Running cost of the tool: ₹45,000 a month.

## Calculation
Net benefit each month = 75,000 - 45,000 = ₹30,000. Payback = 1,50,000 / 30,000 = 5 months. Net gain in year one = 30,000 x 12 - 1,50,000 = 3,60,000 - 1,50,000 = ₹2,10,000.

## Result
The tool pays back its setup cost in 5 months, and by the end of year one it has gained ₹2,10,000 more than it cost.

## Assumptions
We assume the time saved of ₹75,000 stays the same each month and that the running cost does not rise. If staff use it less, the payback takes longer.
