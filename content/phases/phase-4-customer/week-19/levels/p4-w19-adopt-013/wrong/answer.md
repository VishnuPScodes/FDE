# Work out the payback period

## Inputs
Setup cost: ₹1,50,000 one time. Staff time saved: ₹75,000 a month. Running cost of the tool: ₹45,000 a month.

## Calculation
Saving each month = ₹75,000. Payback = 1,50,000 / 75,000 = 2 months. Gain in year one = 75,000 x 12 - 1,50,000 = ₹7,50,000.

## Result
The tool pays back its setup cost in 2 months, and by the end of year one it has gained ₹7,50,000 more than it cost.

## Assumptions
We assume the time saved of ₹75,000 stays the same each month. If staff use it less, the payback takes longer.
